# Video Storage

Almacén automático de videos para TikTok.

Cada video se sube aquí y obtiene una URL pública que Buffer puede usar para publicar en TikTok.

## Estructura

```
videos/
├── 2026-07-29_001.mp4
├── 2026-07-29_002.mp4
└── ...
```

## URL pública

Cada video tiene una URL pública con este formato:
```
https://raw.githubusercontent.com/TriggerXZ/video-storage/main/videos/[nombre].mp4
```

## Uso

Los videos se suben automáticamente desde `C:\Users\dante\content-factory\`.
